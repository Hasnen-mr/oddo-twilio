Dashboard workflow

  1. Start Full Sync — scans all contacts in batches (default 5,000 per batch) with a live progress bar.
  2. Continue Sync — resumes large databases where the previous batch stopped.
  3. Fix False Duplicates — re-scores open rows and removes weak matches automatically.
  4. Review Duplicates — open the review list, see match reasons, merge or ignore.
  5. Scan Reports — download CSV and view manual vs automatic scan history.

Automatic scans run hourly via scheduled action. Manual and automatic jobs both write to Scan Reports.

How duplicate checking works

Detection runs in two stages: candidate grouping (fast) and confidence scoring (accurate). Every suggested pair stores why it was flagged so you can review before merging.

Stage 1 — Find candidates

Contacts are grouped only when they share a strong key:

  • Same normalized email
  • Same normalized phone / mobile
  • Same Tax ID / GST / VAT

City-only grouping is not used — sharing Gurgaon alone does not create a duplicate.

Stage 2 — Score & label

Each candidate pair is scored with exact and fuzzy rules. Examples:

  • 100% — same Tax ID, email, or phone
  • 95%+ — same website
  • 88%+ — very similar company or contact name
  • 85%+ — similar street address (street or ZIP required)

Match reasons on every row

Duplicate Review and the Merge popup show reasons like Same Phone (98%) or Similar Company Name (91%). Weak single signals are rejected — a fuzzy name match alone cannot create a duplicate without a strong identifier.
