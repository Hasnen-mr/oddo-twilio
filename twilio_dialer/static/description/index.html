FAQ

Is the extension completely free?

The extension is freemium — core calling and click-to-call are included at no per-seat cost. Premium features like Auto Dialer are available as paid upgrades.

Which Odoo versions are supported?

Odoo 14 through 19 — Online, Odoo.sh, Enterprise, and Community.

Can calls log back to Odoo automatically?

Yes, via the Post Call Log API in the Odoo API Hub.
