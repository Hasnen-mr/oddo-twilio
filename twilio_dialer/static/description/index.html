FAQ

Common questions

Does this work with Odoo Online and self-hosted Odoo?

Yes — point the API Hub to your own endpoints for contacts and call logs.

Which Odoo versions are supported?

Odoo 14 through 19 (Online, Odoo.sh, Enterprise, and Community).

Do I need a Twilio account?

Yes. Sign in with your Twilio Account SID and Auth Token.

Is the extension freemium?

Yes — core calling and click-to-call are included at no per-seat cost. Premium features like Auto Dialer are paid upgrades. Twilio charges for voice and SMS on your account.

Where are credentials stored?

Locally in browser storage (Chrome extension local storage). They are only sent to Twilio and your own Odoo endpoints.

Can I log calls back to Odoo automatically?

Yes, via the Post Call Log API in the Odoo API Hub.

What if my Odoo API isn't configured yet?

The UI shows sample contacts and logs and guides you to the Setup Odoo Config flow.

Need help configuring endpoints?

Email developer.lifetips@gmail.com and we'll help you set up your Odoo API endpoints.
